# Pac-Man
Pac-Man és un videojoc arcade clàssic en què el jugador controla un personatge groc que recorre un laberint menjant punts i evitant quatre fantasmes.
**Autor/a:** [Marc Contreras Campayo](https://github.com/mcontrerasc2005)
